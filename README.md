# Estrutura de Dados

## O que a disciplina pede

- `01-pilhas`: TAD Pilha.
- `02-filas`: TAD Fila.
- `03-listas`: TAD Lista dinamica duplamente encadeada.
- `04-grafos`: TP 1, TAD de grafo estatico, e TP 2, algoritmos em grafos.

### TP 1 — grafo estatico

As assinaturas das 31 operacoes exigidas estao em `04-grafos/grafo.h`.
A operacao adicional de caminho pedida no enunciado esta em `04-grafos/caminho.h`.
As implementacoes ficam nos arquivos `.c` correspondentes.

### TP 2 — algoritmos em grafos

As assinaturas para voce implementar estao em `04-grafos/algoritmos.h`:

1. `GArvoreGeradoraMinima`
2. `GBuscaLargura`
3. `GBuscaProfundidade`
4. `GCaminhoMaisCurto`
5. `GComponentesConexos`

## Pasta de estudo adicional

`05-arvores` foi criada a seu pedido. Arvores nao aparecem como exigencia nos dois enunciados de TP publicados. A pasta contem apenas a interface de uma arvore binaria de busca e TODOs; a implementacao e sua.
