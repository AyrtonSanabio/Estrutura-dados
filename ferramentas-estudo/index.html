Calcular o custo de um algoritmo

Cole uma função em C ou use o pseudocódigo guiado. Acompanhe cada soma até T(n), O, Ω e Θ.

Analisar código C

Cole uma função C99 ou escolha um exemplo. O código é lido pelo pycparser no servidor local; ele não é executado. Casos fora do modelo recebem uma mensagem explicativa.

Aceita uma função com #include ignorado, for crescente de passo 1 e limites n, V, E ou contador externo. Cada instrução simples conta uma operação. Chamadas, desvios condicionais, recursão e alterações de limites precisam de análise própria.

Ver ou editar o pseudocódigo guiado
Comandos aceitosopop 2for i = 1..nfor j = 1..ifor i = 1..Vfor j = 1..Ewhile x < n doublingend

Uma linha op representa uma operação elementar. op 2 representa duas. O laço logarítmico começa com x=1 e dobra x até x≥n; use-o somente no nível externo. V e E podem representar vértices e arestas: o exemplo de percurso mostra Θ(V + E). A contagem considera operações do corpo e ignora o controle dos laços. Código C arbitrário não é interpretado: sintaxe fora deste modelo produz erro.

Feche cada laço com end. Use até três laços for aninhados.
